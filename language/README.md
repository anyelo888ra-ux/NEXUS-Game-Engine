# NEXUS Programming Languages

This folder is the home of language specifications, parsers, interpreters, standard-library APIs and future tooling maintained by NEXUS Game Engine.

- `nexus-script/`: NEXUS Script, the native browser scripting language.
- Future language adapters may live here, but each must use an explicitly isolated and permissioned runtime.

NEXUS Script is the first-party language. Python, Lua, C/C++ and PHP may be supported later through separate adapters or external toolchains; they are not silently executed by the browser.
